# 腾讯云备案（网站、程序）Skill

这是一份**非官方**的 Codex Skill，帮助办理腾讯云接入的网站 ICP、App 备案，跟进公安联网备案，并区分工信部备案短信核验与业务短信的资质、签名、模板和运营商报备。

它只提供核查方法和操作顺序，不代替主管部门或腾讯云的审核意见，也不保证备案通过。法规、省级要求、控制台字段和办理时限可能变化；每次使用都应重新核对 [Skill 中列出的官方入口](SKILL.md#每次使用前核对的官方入口)。

## 安装

将本仓库的 `SKILL.md` 和 `agents/openai.yaml` 放入 Codex 的 `~/.codex/skills/tencent-cloud-filing/`，保持目录结构不变。之后可说：“使用腾讯云备案（网站、程序）Skill，核查这次网站或 App 备案的材料和进度。”

## 范围

- 网站 ICP 与 App 备案：先核对主体、域名、接入资源、真实业务和材料，再跟进服务商审核、工信部核验及管局结果。
- 公安联网备案：与 ICP 分别跟踪，按实际开通情况和现行要求办理。
- 小程序及经营性许可：先确认适用渠道和要求，不直接套用网站或 App 表单。
- 业务短信：与备案核验分开，单独确认资质、签名、模板、运营商报备、接入和实际收码。

本公开版不包含真实企业案例、个人身份资料、证件、联系方式、账号凭据、备案数据码或内部截图。
